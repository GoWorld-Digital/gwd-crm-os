## Why this project exists

GWD may develop an AI-first **CRM and commercial operations product** for future Ventures or third-party clients. The initial codebase is an **upstream-derived technical candidate** used to evaluate features, maintainability, integration, security, commercial licensing and operating models.

**This repository is not the CRM currently operating GWD, nor evidence of a launched product, customers, active WhatsApp channels or approved business revenue.** Its presence does not authorize a new Venture, a deployment or collection of real leads.

## Role in the AI-Native ecosystem

| Component | Responsibility |
|---|---|
| **CRM** | Authorized customer, lead, commercial pipeline and consent records |
| **AtlasHQ** | Proposed enterprise workspace and collaboration layer, not a second customer database |
| **Cortex** | Scoped institutional knowledge and references; no bulk replication of raw CRM/client data |
| **GWD Governance / Portfolio** | Approves a Venture mandate, operator, commercial responsibilities, privacy and budgets |

Any CRM-to-Cortex integration must be built as **purpose-scoped, permissioned adapters** with data minimization, provenance, retention/deletion propagation, customer isolation, LGPD/privacy review and negative access tests.

## Before a GWD pilot

A bounded technical mandate must identify the target product, code provenance and all license obligations, owner, environment, integration API, secrets management, simulated data, isolation model and recovery plan. Production needs independent verification and the GWD **D11** human-owner recovery gate.

The experimental [GWD Core CRM adapter PR](https://github.com/GoWorld-Digital/gwd-core/pull/19) is **not** proof of an adopted CRM, deployed integration or approval to touch real customers.
